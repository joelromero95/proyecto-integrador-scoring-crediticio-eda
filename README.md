# EDA - Modelo de Scoring Crediticio para Clientes No Bancarizados

Este repositorio contiene el análisis exploratorio de datos realizado para el Proyecto Integrador de la Maestría en Inteligencia Artificial Aplicada.

## Objetivo

Analizar la estructura, calidad y comportamiento de los datasets disponibles para evaluar su utilidad en el desarrollo de un modelo de Machine Learning orientado a estimar la solvencia crediticia de clientes no bancarizados.

## Datasets analizados

Por motivos de privacidad, los datos originales no se incluyen en este repositorio.

Los datasets considerados son:

1. Comportamiento histórico de nómina
2. Perfil sociodemográfico y relación bancaria
3. Domicilios registrados
4. Geocodificación de domicilios
5. Enriquecimiento geográfico y movilidad

## Contenido del análisis

El EDA incluye:

- Revisión de estructura de los datasets
- Identificación de valores faltantes
- Estadísticas descriptivas
- Análisis de variables numéricas y categóricas
- Revisión de cardinalidad
- Identificación preliminar de valores atípicos
- Revisión de variables temporales
- Consideraciones iniciales de preprocesamiento
